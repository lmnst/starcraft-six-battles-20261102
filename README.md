# 六局交战回放

六场本地 Bot 对战的完整静音视频，支持暂停、拖动、倍速、全屏、跳到已抽查的交战位置，并提供原始 `.rep` 下载。

站点文件位于 `dist/`，使用 GitHub Pages 工作流部署。只托管已导出的视频、回放、缩略图及验证摘要，不包含游戏 MPQ。

视频由保留的 Windows OpenBWData 引擎推进回放，自动镜头读取引擎状态并导出为 H.264。每四个游戏帧输出一帧，以 12fps 编码；默认播放约为游戏速度的两倍。网页不重新模拟游戏。`verification.json` 记录回放与视频哈希、帧数、交战采样和原生状态校验。

胜负来自原始评测记录。tscmoo 是身份未确认的作者源码候选，本页不是官方 benchmark。
